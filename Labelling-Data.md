## What is labelling the data and why do we label.

In AWS SageMaker, labeling data is a critical step in supervised machine learning workflows.
Supervised learning algorithms require labeled data to learn patterns and relationships between input features and their corresponding outputs.

Here the advantages of labelling the data
- Its proves the model accuracy.
- Labeling helps to categorize and organize data.
- It is used to calculate metrics like accuracy, precision, recall, and F1-score.

## Usecases of Labelling
- Image Labeling: Annotating objects or regions in images for computer vision tasks like object detection or segmentation.
- Text Labeling: Assigning sentiment or topic categories to text data for natural language processing.
- Tabular Data Labeling: Classifying rows of structured data for prediction tasks.
- Audio Labeling: Identifying speakers or transcribing audio for speech recognition tasks.
